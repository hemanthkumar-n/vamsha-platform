# Vamsha Family Web Design QA

## Target

Canva family-web reference supplied by the project owner, adapted to the
viewer-centric Vamsha relationship model.

- Desktop viewport: 1280 x 720
- Mobile viewport: 390 x 844
- Viewer remains centered when the viewport changes
- Male, female, married, and active-viewer states are visually distinct
- Generation bands and relationship connectors remain readable
- Viewer selector, profile cards, projection navigation, and zoom controls
  retain their interaction contracts
- No browser console warnings or errors
