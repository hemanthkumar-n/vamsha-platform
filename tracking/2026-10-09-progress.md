## Product goal

Vamsha answers “Who is this person to me, and what do I call them?” using one
family graph, the selected viewer, language context, and family calling conventions.
The longer-term goal includes private family collaboration and legacy preservation.

## Verified project baseline

- Flutter family web with zoom, pan, viewer switching, and person profiles.
- Graph-based relationship projection with English and Telugu calling display.
- Family-specific calling overrides, aliases, and sibling-order metadata.
- Supabase read integration with a checked-in local family graph fallback.
- Founder canvas positions remain predefined; automatic layout is unfinished.
- Authentication, editable family records, invitations, and private collaboration
  remain unfinished.

## Browser preview

The configured debug preview stalled before creating the app view. The exact
startup cause has not been established. An offline preview using the checked-in
family graph rendered successfully.

The working preview was served at `http://127.0.0.1:6015/?preview=offline`.
The query parameter is only a browser URL marker; the offline behavior comes from
building without Supabase Dart defines.

To recreate that preview from the repository root:

```bash
cd mobile_app
flutter build web --no-web-resources-cdn --no-pub
python3 -m http.server 6015 --bind 127.0.0.1 --directory build/web
```

Open `http://127.0.0.1:6015/` and keep the server running. Rebuild and refresh the
browser after code changes. These instructions assume Flutter dependencies are
already installed; otherwise run `flutter pub get` first.
